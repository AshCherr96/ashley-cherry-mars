# Ashley Cherry | Frontend Developer Portfolio

A responsive, interactive professional portfolio built to showcase my web development skills, professional experience, and live projects fetched directly from GitHub.

## 🚀 Live Demo
[View my live portfolio here](https://ashcherr96.github.io/portfolio-project/)

## ✨ Key Features
* **Dynamic Project Fetching:** Integrates with the **GitHub API** to automatically display my latest repositories.
* **Interactive Message Board:** A custom-built form that allows users to leave, edit, and remove messages using **DOM Manipulation**.
* **Mobile-First Responsive Design:** Built using **CSS Grid and Flexbox** to ensure a seamless experience on mobile, tablet, and desktop.
* **Professional UX:** Includes smooth scrolling, sticky navigation, and custom CSS tooltips for social links.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure for accessibility and SEO.
* **CSS3:** Custom layouts using Grid, Flexbox, and Media Queries.
* **JavaScript (ES6+):** Fetch API, DOM manipulation, and asynchronous programming.
* **FontAwesome:** High-quality icons for social connectivity.

## 📈 Learning Journey
This project was developed as part of the **Code The Dream** curriculum. Throughout the development process, I mastered:
1.  **DOM Interactivity:** Handling user events to change page content in real-time.
2.  **API Integration:** Successfully handling Promises and JSON data from external servers.
3.  **Cross-Device Optimization:** Designing for different screen sizes starting from the mobile view up.
